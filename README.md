# 🚀 B.Tech CST 4-Year Gamified Roadmap Platform

A modern, interactive, and gamified web platform engineered specifically for **B.Tech Computer Science & Technology (CST)** students. Designed to guide students seamlessly from **Year 1 fundamentals** to **Year 4 top-tier tech placements and job readiness**.

---

## ✨ Features

- 🎯 **Semester-by-Semester Curriculum Breakdown**:
  - **Year 1:** Core C Programming, Linux Terminal, Git/GitHub, Discrete Math & Hardware Logic.
  - **Year 2:** Advanced Data Structures, LeetCode Problem Solving, Operating Systems, DBMS & Computer Networks.
  - **Year 3:** MERN / AI Specialization, Hackathons, Open Source Contributions & Summer Internships.
  - **Year 4:** Top 100 DSA Revision, High-Level System Design (HLD/LLD), Mock HR/Technical Interviews & Major Capstone Projects.

- 🎮 **Gamification Mechanics**:
  - **XP & Leveling Engine:** Earn experience points by completing real milestones.
  - **Achievement Badges:** Unlock badges like *C Code Ninja*, *DSA Warrior*, and *Software Titan*.
  - **Sound Synth Effects & Confetti:** Web Audio API sound feedback upon task completion.

- 🛠️ **Custom Goal Creator**: Add custom personalized targets dynamically to any semester.
- 📁 **Project Blueprints**: Practical portfolio project ideas for each year of college.
- 📚 **Filterable Resource Library**: Quick search for top YouTube playlists, documentation, and coding platforms.
- 💾 **Persistent Storage**: All progress saves automatically in browser `localStorage`.

---

## 🛠️ Built With

- **HTML5 & Modern JavaScript (ES6+)**
- **Tailwind CSS** (via CDN for clean utility styling)
- **FontAwesome 6** (Icons)
- **Canvas Confetti API** (Particle effects)
- **Web Audio API** (Procedural sound synthesis)
